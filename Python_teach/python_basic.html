Python 互動式初階教學

滑鼠游標移至卡片上以體驗 CSS 互動特效，輕鬆掌握 16 個核心基礎概念。

🚀 學習指南：Python 的核心精神

Python 是一門強調可讀性與簡潔語法的程式語言。它的設計哲學是「優雅、明確、簡單」。

  • 變數與資料型別： 不需事先宣告型別（動態型別），直接賦值即可使用。常見包含整數 (int)、浮點數 (float)、字串 (str) 與布林值 (bool)。
  • 資料結構： 串列 (List)、字典 (Dictionary)、集合 (Set) 與元組 (Tuple) 讓資料管理變得極為彈性。
  • 流程控制： 使用 if...elif...else 進行條件判斷，使用 for 與 while 處理重複性工作。注意：Python 強制使用「縮排 (Indentation)」來定義程式區塊。
  • 函式與模組： 透過 def 定義重複使用的邏輯，並可使用 import 引入強大的標準函式庫。

01 Hello World

學習任何語言的第一步，在螢幕上印出文字。

print("Hello, Python World!")
> Hello, Python World!

02 變數與賦值

Python 會自動判斷變數型態，無需宣告。

name = "Alice"
age = 25
print(f"{name} is {age} years old.")
> Alice is 25 years old.

03 基本算術運算

支援加減乘除、取餘數及次方運算。

a, b = 10, 3
print("相除:", a / b)
print("取整數:", a // b)
print("取餘數:", a % b)
print("次方:", b ** 2)
> 相除: 3.3333333333333335 > 取整數: 3 > 取餘數: 1 > 次方: 9

04 字串操作

字串可以相加、重複，或轉換大小寫。

text = "python"
print(text.capitalize())
print(text.upper())
print(text * 3)
> Python > PYTHON > pythonpythonpython

05 條件判斷 (if-else)

根據條件執行不同的程式區塊。

score = 85
if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
else:
    print("Grade: C")
> Grade: B

06 For 迴圈

搭配 range() 或直接走訪序列。

for i in range(3):
    print(f"迴圈次數: {i}")
> 迴圈次數: 0 > 迴圈次數: 1 > 迴圈次數: 2

07 While 迴圈

當條件成立時，持續執行區塊內的程式碼。

count = 3
while count > 0:
    print(count)
    count -= 1
print("Go!")
> 3 > 2 > 1 > Go!

08 串列 (List)

可變動的有序集合，可隨時新增或刪除元素。

fruits = ['apple', 'banana']
fruits.append('cherry')
print(fruits[0])
print(fruits)
> apple > ['apple', 'banana', 'cherry']

09 元組 (Tuple)

與串列相似，但建立後「不可修改」，安全性較高。

dimensions = (1920, 1080)
print(f"寬度: {dimensions[0]}")
# dimensions[0] = 800 (這行會發生錯誤)
> 寬度: 1920

10 字典 (Dictionary)

透過鍵值對 (Key-Value) 來儲存與查詢資料。

user = {"name": "Bob", "role": "Admin"}
print(user["name"])
user["age"] = 30
print(user.keys())
> Bob > dict_keys(['name', 'role', 'age'])

11 集合 (Set)

無序且不重複的元素集合，常用於去除重複資料。

nums = {1, 2, 2, 3, 3, 3}
print(nums)
nums.add(4)
print(nums)
> {1, 2, 3} > {1, 2, 3, 4}

12 自訂函式 (Function)

將重複的邏輯打包，提高程式碼的重用性。

def greet(name="Guest"):
    return f"Hello, {name}!"

print(greet("Emma"))
print(greet())
> Hello, Emma! > Hello, Guest!

13 引入模組 (Import)

使用 Python 內建或第三方庫擴充功能。

import math
print("圓周率:", round(math.pi, 2))
print("9 的平方根:", math.sqrt(9))
> 圓周率: 3.14 > 9 的平方根: 3.0

14 異常處理 (Try-Except)

避免程式因為預期外的錯誤而崩潰。

try:
    result = 10 / 0
except ZeroDivisionError:
    print("錯誤：不能除以零！")
finally:
    print("執行完畢")
> 錯誤：不能除以零！ > 執行完畢

15 列表推導式

用極短的語法快速產生新的串列 (List Comprehension)。

squares = [x**2 for x in range(1, 6)]
print(squares)
> [1, 4, 9, 16, 25]

16 Lambda 匿名函式

不需命名的單行小函式，常搭配 map 或 filter 使用。

multiply = lambda x, y: x * y
print("5 * 4 =", multiply(5, 4))
> 5 * 4 = 20
