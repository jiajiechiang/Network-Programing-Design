Python Socket 網路通訊基礎教學

點對點資料傳輸：TCP 與 UDP 的 6 大實戰演練

什麼是 Socket？
Socket (通訊端點) 是作業系統提供的介面，讓程式能夠透過網路發送或接收資料。學習 Socket 是理解所有上層網路應用 (如 HTTP, FTP, 遊戲連線) 的底層基礎。

兩大核心協定：
1. TCP (傳輸控制協定)：需要「連線建立 (三向交握)」，保證資料正確且按順序到達，適合檔案傳輸、網頁。
2. UDP (使用者資料包協定)：不需要連線，直接「丟」資料，速度快但不保證送達，適合即時語音、線上遊戲。

Demo 1 建立 TCP 伺服器 (Server)

TCP 伺服器必須經過 bind() 綁定位址、listen() 開始監聽，並透過 accept() 接受客戶端的連線請求。

tcp_server.py
import socket

HOST = '127.0.0.1'  # 本地端 IP
PORT = 8888         # 監聽的 Port 號

# AF_INET = IPv4, SOCK_STREAM = TCP 協定
with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as server_sock:
    server_sock.bind((HOST, PORT))
    server_sock.listen()
    print(f"TCP 伺服器啟動，等待 {HOST}:{PORT} 的連線...")
    
    # accept() 會阻塞程式，直到有客戶端連線
    conn, addr = server_sock.accept()
    with conn:
        print(f"已接受來自 {addr} 的連線")
        
        # 接收資料 (一次最多接收 1024 bytes)
        data = conn.recv(1024)
        print("收到客戶端訊息：", data.decode('utf-8'))
        
        # 回傳訊息給客戶端 (必須編碼成 bytes)
        conn.sendall("哈囉！TCP 伺服器已收到你的訊息。".encode('utf-8'))

Demo 2 建立 TCP 客戶端 (Client)

TCP 客戶端比較簡單，建立 Socket 後，直接呼叫 connect() 連向伺服器的 IP 與 Port。

tcp_client.py
import socket

HOST = '127.0.0.1'  # 目標伺服器 IP
PORT = 8888         # 目標伺服器 Port

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as client_sock:
    # 發起連線
    client_sock.connect((HOST, PORT))
    
    # 發送訊息給伺服器
    message = "你好，這是一條測試訊息！"
    client_sock.sendall(message.encode('utf-8'))
    
    # 接收伺服器的回覆
    data = client_sock.recv(1024)
    print("收到伺服器回傳：", data.decode('utf-8'))

Demo 3 建立 UDP 伺服器 (Server)

UDP 不需要建立連線通道，伺服器 bind() 綁定位址後，直接用 recvfrom() 接收任何丟過來的資料包。

udp_server.py
import socket

HOST = '127.0.0.1'
PORT = 9999

# SOCK_DGRAM = UDP 協定
with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as server_sock:
    server_sock.bind((HOST, PORT))
    print(f"UDP 伺服器啟動，正在 {HOST}:{PORT} 接收封包...")
    
    # recvfrom 會回傳資料本身，以及發送者的位址 (IP, Port)
    data, client_addr = server_sock.recvfrom(1024)
    print(f"收到來自 {client_addr} 的封包：", data.decode('utf-8'))
    
    # 針對該位址回傳確認訊息
    reply = "UDP 伺服器已成功接收封包！"
    server_sock.sendto(reply.encode('utf-8'), client_addr)

Demo 4 建立 UDP 客戶端 (Client)

UDP 客戶端完全不需要 connect()，準備好資料後，指定目標 IP 與 Port，用 sendto() 像射飛鏢一樣把資料丟出去。

udp_client.py
import socket

SERVER_HOST = '127.0.0.1'
SERVER_PORT = 9999

with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as client_sock:
    # 直接將資料發送至目標位址
    message = "這是一顆 UDP 飛彈資料包！"
    client_sock.sendto(message.encode('utf-8'), (SERVER_HOST, SERVER_PORT))
    
    # 接收伺服器的回覆
    data, addr = client_sock.recvfrom(1024)
    print(f"收到伺服器 {addr} 回傳：", data.decode('utf-8'))

Demo 5 TCP 連續通訊：Echo 伺服器

實務上的伺服器不會只處理一次請求就關閉。我們加上 while True 迴圈，讓伺服器能持續與客戶端對話 (這裡示範收到什麼就回傳什麼的 Echo Server)。

tcp_echo_server.py
import socket

HOST = '127.0.0.1'
PORT = 50000

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
    s.bind((HOST, PORT))
    s.listen()
    print("Echo 伺服器啟動，等待連線...")
    
    conn, addr = s.accept()
    with conn:
        print(f"客戶端 {addr} 已連線")
        
        # 持續接收該客戶端的資料
        while True:
            data = conn.recv(1024)
            # 若 data 為空，代表客戶端已主動斷線
            if not data:
                print("客戶端已斷線。")
                break
                
            msg = data.decode('utf-8')
            print(f"收到訊息: {msg}")
            
            # 將收到的訊息加上前綴後原封不動回傳 (Echo)
            reply = f"[Echo]: {msg}"
            conn.sendall(reply.encode('utf-8'))

Demo 6 TCP 連續通訊：可持續輸入的客戶端

搭配上面的 Echo 伺服器，客戶端也使用迴圈搭配 input()，讓使用者可以不斷輸入訊息發送給伺服器，直到輸入 exit 為止。

tcp_interactive_client.py
import socket

HOST = '127.0.0.1'
PORT = 50000

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
    s.connect((HOST, PORT))
    print("已連線至 Echo 伺服器！(輸入 'exit' 離開)")
    
    while True:
        # 等待使用者輸入
        msg = input("請輸入訊息 > ")
        
        if msg.lower() == 'exit':
            print("關閉連線。")
            break
            
        # 發送訊息
        s.sendall(msg.encode('utf-8'))
        
        # 接收伺服器回覆
        data = s.recv(1024)
        print("伺服器回傳: ", data.decode('utf-8'))

測試方法：請開啟兩個終端機 (Terminal)。先在第一個終端機執行 tcp_echo_server.py，再到第二個終端機執行 tcp_interactive_client.py 即可測試對話。
