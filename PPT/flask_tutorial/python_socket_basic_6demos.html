Python Socket 網路通訊基礎

底層協定解析：TCP 與 UDP 點對點連線的 6 大實戰

Socket 通訊核心觀念：
socket 是作業系統提供給應用程式的網路介面。通訊協定主要分為兩種：
1. TCP (傳輸控制協定)：需要建立連線 (三向交握)，資料保證送達且順序正確，適合檔案傳輸與網頁連線。
2. UDP (使用者資料包協定)：不需要建立連線，送出即不管，速度快但可能會掉包，適合即時影音串流或遊戲。

Demo 1 TCP 伺服器 (Server)：監聽與接收

伺服器的工作是綁定一個 IP 與 Port，接著開始「監聽 (listen)」，等待客戶端連線。連線後，透過 accept() 取得連線物件來收發資料。

tcp_server.py
import socket

HOST = '127.0.0.1'  # 本地端 IP (Localhost)
PORT = 65432        # 監聽的 Port 號 (建議大於 1024)

# 1. 建立 Socket 物件。AF_INET 代表 IPv4，SOCK_STREAM 代表 TCP 協定
with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as server_socket:
    # 2. 綁定 IP 與 Port
    server_socket.bind((HOST, PORT))
    
    # 3. 開始監聽連線要求
    server_socket.listen()
    print(f"伺服器啟動，正在監聽 {HOST}:{PORT}...")
    
    # 4. 接受客戶端連線 (程式會卡在這裡等待，直到有人連入)
    conn, addr = server_socket.accept()
    with conn:
        print(f"已連線！客戶端位址：", addr)
        
        # 5. 接收資料 (最多 1024 bytes)
        data = conn.recv(1024)
        print("收到客戶端訊息：", data.decode('utf-8'))
        
        # 6. 回傳資料給客戶端 (需編碼為 bytes)
        conn.sendall("哈囉！我是 TCP 伺服器，已收到你的訊息！".encode('utf-8'))

Demo 2 TCP 客戶端 (Client)：發送與接收

客戶端不需要綁定 Port，只需知道伺服器的 IP 與 Port，呼叫 connect() 發起連線即可傳輸資料。

tcp_client.py
import socket

HOST = '127.0.0.1'  # 伺服器的 IP
PORT = 65432        # 伺服器的 Port

# 1. 建立 TCP Socket
with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as client_socket:
    # 2. 連線至伺服器
    client_socket.connect((HOST, PORT))
    
    # 3. 發送訊息 (將字串編碼轉換成 bytes 格式)
    message = "你好！我是 TCP 客戶端。"
    client_socket.sendall(message.encode('utf-8'))
    
    # 4. 接收伺服器回傳的訊息
    data = client_socket.recv(1024)

print("收到伺服器回傳：", data.decode('utf-8'))

Demo 3 UDP 伺服器：無連線接收

UDP 不需要 listen() 也不需要 accept()。綁定 Port 後，直接透過 recvfrom() 等待任何人丟資料過來。

udp_server.py
import socket

HOST = '127.0.0.1'
PORT = 9999

# 1. 建立 Socket 物件。SOCK_DGRAM 代表 UDP 協定
with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as server_socket:
    # 2. 綁定 IP 與 Port
    server_socket.bind((HOST, PORT))
    print(f"UDP 伺服器啟動，正在 {HOST}:{PORT} 等待資料...")
    
    # 3. 直接接收資料，recvfrom 會同時回傳資料與發送者的地址 (addr)
    data, addr = server_socket.recvfrom(1024)
    print(f"收到來自 {addr} 的訊息：", data.decode('utf-8'))
    
    # 4. 根據發送者的地址回傳訊息
    reply = "UDP 伺服器已收到你的封包！"
    server_socket.sendto(reply.encode('utf-8'), addr)

Demo 4 UDP 客戶端：直接發射資料包

因為 UDP 不用建立連線，所以不需要 connect()，只要指定目標 IP 與 Port，就能使用 sendto() 將資料丟出去。

udp_client.py
import socket

SERVER_HOST = '127.0.0.1'
SERVER_PORT = 9999

# 1. 建立 UDP Socket
with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as client_socket:
    # 2. 直接將訊息發送到指定的 IP 與 Port
    message = "咻！這是一顆 UDP 資料包。"
    client_socket.sendto(message.encode('utf-8'), (SERVER_HOST, SERVER_PORT))
    
    # 3. 接收伺服器的回覆
    data, server_addr = client_socket.recvfrom(1024)

print(f"收到伺服器 {server_addr} 回傳：", data.decode('utf-8'))

Demo 5 TCP 連續通訊：簡易聊天室伺服器

前面的範例都是「一問一答」後程式就結束了。實務上，我們會使用 while True 無窮迴圈來保持通訊不斷線。

chat_server.py
import socket

HOST = '127.0.0.1'
PORT = 50000

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
    s.bind((HOST, PORT))
    s.listen()
    print("聊天伺服器啟動，等待連線...")
    
    conn, addr = s.accept()
    with conn:
        print(f"客戶端 {addr} 進入聊天室！")
        
        # 無窮迴圈保持對話
        while True:
            # 接收客戶端訊息
            data = conn.recv(1024)
            if not data:
                print("客戶端已斷線。")
                break # 如果沒收到資料，代表對方斷線，跳出迴圈
                
            print(f"Client: {data.decode('utf-8')}")
            
            # 伺服器輸入回覆
            reply = input("Server (你): ")
            conn.sendall(reply.encode('utf-8'))

Demo 6 TCP 連續通訊：簡易聊天室客戶端

配合上方的聊天室伺服器，客戶端也使用無窮迴圈，實作「先發送、後接收」的輪替溝通機制。

chat_client.py
import socket

HOST = '127.0.0.1'
PORT = 50000

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
    s.connect((HOST, PORT))
    print("已連線至聊天伺服器！輸入 'exit' 可離開。")
    
    while True:
        # 客戶端輸入訊息
        msg = input("Client (你): ")
        if msg.lower() == 'exit':
            break
            
        # 發送訊息
        s.sendall(msg.encode('utf-8'))
        
        # 接收伺服器回覆
        data = s.recv(1024)
        if not data:
            print("伺服器已關閉連線。")
            break
            
        print(f"Server: {data.decode('utf-8')}")

測試方法：請開啟兩個終端機 (Terminal)。先在第一個終端機執行 chat_server.py，再到第二個終端機執行 chat_client.py，即可開始互動對話！
