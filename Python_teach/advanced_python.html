01 快取最佳化 (LRU Cache)

使用 functools.lru_cache 將耗時函式的結果暫存於記憶體，極大提升遞迴效能。

import functools

@functools.lru_cache(maxsize=None)
def fib(n):
    if n < 2: return n
    return fib(n-1) + fib(n-2)

print("Fibonacci(50):", fib(50))
Fibonacci(50): 12586269025

02 非同步 I/O (asyncio)

使用 async/await 處理高併發 I/O 操作，不會阻塞主執行緒。

import asyncio

async def fetch_data(id):
    await asyncio.sleep(0.1)
    return f"Data {id}"

async def main():
    tasks = [fetch_data(i) for i in range(3)]
    res = await asyncio.gather(*tasks)
    print(res)

asyncio.run(main())
['Data 0', 'Data 1', 'Data 2']

03 描述器協議 (Descriptors)

透過實作 __get__ 與 __set__ 來攔截並控制類別屬性的存取。

class IntegerOnly:
    def __set_name__(self, owner, name):
        self.name = name
    def __set__(self, obj, value):
        if not isinstance(value, int):
            raise ValueError("Must be int")
        obj.__dict__[self.name] = value

class User:
    age = IntegerOnly()

u = User()
u.age = 25
print(u.age)
25
(若賦值字串則會引發 ValueError)

04 元類別 (Metaclass)

類別的「類別」。可用來攔截類別的建立過程，強制套用設計模式(如 Singleton)。

class SingletonMeta(type):
    _instances = {}
    def __call__(cls, *args, **kwargs):
        if cls not in cls._instances:
            inst = super().__call__(*args, **kwargs)
            cls._instances[cls] = inst
        return cls._instances[cls]

class DB(metaclass=SingletonMeta):
    pass

print(DB() is DB())
True

05 __slots__ 記憶體最佳化

關閉類別實例的 __dict__，使用固定長度的陣列存儲屬性，大幅節省記憶體。

class Point:
    # 限制只能擁有 x, y 屬性
    __slots__ = ['x', 'y']
    
    def __init__(self, x, y):
        self.x = x
        self.y = y

p = Point(10, 20)
# p.z = 30  # 會引發 AttributeError
print(p.x, p.y)
10 20

06 上下文管理器產生器

利用 @contextmanager 與 yield，將一般函式快速轉為 with 語法支援的物件。

from contextlib import contextmanager

@contextmanager
def timer():
    import time
    start = time.time()
    yield
    print(f"耗時: {time.time() - start:.4f}s")

with timer():
    sum(i*i for i in range(10000))
耗時: 0.0012s (依實際硬體而異)

07 單分派泛型 (Single Dispatch)

Python 也能實作類似其他語言的「函式多載(Overload)」，根據參數型別執行不同邏輯。

from functools import singledispatch

@singledispatch
def process(data):
    print("處理未知型態:", data)

@process.register(int)
def _(data):
    print("處理整數:", data * 2)

process(10)
process("Hello")
處理整數: 20
處理未知型態: Hello

08 資料類別 (Dataclasses)

自動生成 __init__, __repr__, __eq__，適合用來建立純資料容器。

from dataclasses import dataclass, field

@dataclass
class Inventory:
    item: str
    price: float
    # 使用 default_factory 初始化可變物件
    tags: list = field(default_factory=list)

inv = Inventory("Sword", 99.9, ["Weapon"])
print(inv)
Inventory(item='Sword', price=99.9, tags=['Weapon'])

09 帶參數的裝飾器

透過三層函式嵌套，建立可以接收參數的自訂裝飾器。

def repeat(times):
    def decorator_repeat(func):
        def wrapper(*args, **kwargs):
            for _ in range(times):
                res = func(*args, **kwargs)
            return res
        return wrapper
    return decorator_repeat

@repeat(times=3)
def greet(name):
    print(f"Hi {name}")

greet("Neo")
Hi Neo
Hi Neo
Hi Neo

10 yield from (委派產生器)

用於將一個產生器的操作直接委派給另一個可迭代物件，簡化雙層 for 迴圈。

def flatten(nested_list):
    for item in nested_list:
        if isinstance(item, list):
            yield from flatten(item)
        else:
            yield item

nested = [1, [2, [3, 4]], 5]
print(list(flatten(nested)))
[1, 2, 3, 4, 5]

11 __new__ vs __init__

__new__ 負責「創造」物件實例，而 __init__ 負責「初始化」。

class Factory:
    def __new__(cls, value):
        if value > 0:
            return super().__new__(cls)
        return None # 拒絕建立
        
    def __init__(self, value):
        self.value = value

obj1 = Factory(10)
obj2 = Factory(-5)
print(obj1, obj2)
<__main__.Factory object at ...> None

12 抽象基底類別 (ABC)

定義標準介面，強制子類別必須實作特定方法，否則無法實例化。

from abc import ABC, abstractmethod

class PaymentABC(ABC):
    @abstractmethod
    def pay(self, amount):
        pass

class Stripe(PaymentABC):
    def pay(self, amount):
        print(f"Paid ${amount}")

Stripe().pay(50)
# PaymentABC() # 會引發 TypeError
Paid $50

13 弱參照 (Weakref)

建立對物件的參照，但不會增加其引用計數 (Reference Count)，有助於避免記憶體洩漏。

import weakref

class HeavyObject:
    pass

obj = HeavyObject()
ref = weakref.ref(obj)

print("Before del:", ref())
del obj
print("After del:", ref())
Before del: <__main__.HeavyObject object>
After del: None

14 猴子修補 (Monkey Patching)

在執行期間動態替換類別或模組的方法，常用於單元測試的 Mock。

class API:
    def get_data(self):
        return "Real Data"

# 動態修改行為
def fake_get_data(self):
    return "Mocked Data"

API.get_data = fake_get_data

api = API()
print(api.get_data())
Mocked Data

15 偏函式 (functools.partial)

預先填入函式的某些參數，產生一個新的、更少參數的函式，方便回呼(Callback)設計。

from functools import partial

def power(base, exp):
    return base ** exp

# 固定 exp 參數為 2
square = partial(power, exp=2)
cube = partial(power, exp=3)

print("Square(5):", square(5))
print("Cube(5):", cube(5))
Square(5): 25
Cube(5): 125

16 協定型別提示 (Protocols)

Python 3.8+ 引入。支援結構型子型別 (Duck Typing)，只要類別實作了指定方法即可通過靜態檢查。

from typing import Protocol

class Flyable(Protocol):
    def fly(self) -> None: ...

class Bird:
    def fly(self):
        print("Flapping wings!")

# 靜態檢查器知道 Bird 符合 Flyable
def make_it_fly(f: Flyable):
    f.fly()

make_it_fly(Bird())
Flapping wings!
