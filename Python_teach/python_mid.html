Python 中階互動式教學

掌握進階特性，寫出更 Pythonic (優雅且高效) 的程式碼。請將滑鼠移至卡片上以觸發霓虹特效！

⚡ 中階核心能力指標

在初階中我們學會了如何讓程式「動起來」，中階的目標則是讓程式「更好維護、效能更高、更具擴充性」。

  • 進階資料處理： 熟練使用推導式 (Comprehension) 簡化迴圈，並能運用高階函式如 map、filter 進行函數式編程。
  • 彈性的函式設計： 理解 *args 與 **kwargs 動態參數，並精通 裝飾器 (Decorator) 來為函式動態添加功能。
  • 記憶體管理與效能： 學會使用 產生器 (Generator) (yield) 與迭代器，處理巨量資料時不佔據大量記憶體。
  • 物件導向設計 (OOP)： 掌握類別 (Class)、繼承 (Inheritance)、多型，以及好用的魔法方法 (Magic Methods)。
  • 穩健的程式架構： 精通例外處理機制 (Exception Handling)、上下文管理器 (with 語法)，確保資源安全釋放。

01 進階列表推導式

結合 if-else 的 List Comprehension，寫法更簡潔優雅。

nums = [1, 2, 3, 4, 5]
# 偶數平方，奇數設為 0
res = [x**2 if x%2==0 else 0 for x in nums]
print(res)
> [0, 4, 0, 16, 0]

02 動態參數 *args & **kwargs

允許函式接收任意數量的位置參數與關鍵字參數。

def info(*args, **kwargs):
    print("Args:", args)
    print("Kwargs:", kwargs)

info(1, 2, name="Alice", age=25)
> Args: (1, 2)
> Kwargs: {'name': 'Alice', 'age': 25}

03 產生器 (Generator)

使用 yield 暫停並回傳值，節省龐大記憶體消耗。

def countdown(n):
    while n > 0:
        yield n
        n -= 1

for num in countdown(3):
    print(num, end=" ")
> 3 2 1

04 裝飾器 (Decorator)

在不修改原函式程式碼的情況下，動態為其擴充功能。

def logger(func):
    def wrapper():
        print("執行前紀錄...")
        func()
    return wrapper

@logger
def say_hi():
    print("Hi!")

say_hi()
> 執行前紀錄...
> Hi!

05 map 與 filter 高階函式

針對序列元素進行批量轉換或篩選，常用於函數式編程。

nums = [1, 2, 3, 4]
squared = list(map(lambda x: x**2, nums))
evens = list(filter(lambda x: x%2==0, nums))
print("平方:", squared)
print("偶數:", evens)
> 平方: [1, 4, 9, 16]
> 偶數: [2, 4]

06 類別與物件 (OOP 基礎)

定義物件的藍圖，包含屬性 (屬性) 與方法 (行為)。

class Dog:
    def __init__(self, name):
        self.name = name
    def bark(self):
        return f"{self.name} 說：汪汪！"

my_dog = Dog("Rex")
print(my_dog.bark())
> Rex 說：汪汪！

07 類別的繼承 (Inheritance)

子類別可繼承父類別的功能，並進行擴展或覆寫。

class Animal:
    def speak(self): return "..."

class Cat(Animal):
    def speak(self): return "喵~"

kitty = Cat()
print(kitty.speak())
> 喵~

08 魔法方法 (Magic Methods)

透過雙底線方法 (如 __str__) 改變物件的內建行為。

class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y
    def __str__(self):
        return f"({self.x}, {self.y})"

p = Point(3, 4)
print(p) # 自動呼叫 __str__
> (3, 4)

09 上下文管理器 (Context Manager)

使用 with 語法自動處理資源的開啟與關閉 (如檔案)。

# 自動處理檔案關閉，即使發生例外也不怕
with open("test.txt", "w") as f:
    f.write("Hello World")

with open("test.txt", "r") as f:
    print(f.read())
> Hello World

10 自訂例外處理 (Custom Exception)

除了攔截錯誤，還能根據業務邏輯拋出 (raise) 自訂錯誤。

class AgeError(Exception):
    pass

age = -5
try:
    if age < 0:
        raise AgeError("年齡不能是負數！")
except AgeError as e:
    print(f"捕獲錯誤：{e}")
> 捕獲錯誤：年齡不能是負數！

11 JSON 資料解析

Python 字典與 JSON 字串之間的互相轉換 (Serialization)。

import json
data_dict = {"name": "Bob", "id": 1}
# 字典轉 JSON 字串
json_str = json.dumps(data_dict)
print(json_str)
# JSON 轉回字典
print(json.loads(json_str)["name"])
> {"name": "Bob", "id": 1}
> Bob

12 正規表達式 (Regex)

使用 re 模組進行複雜的字串匹配與萃取。

import re
text = "My email is test@example.com"
# 尋找 Email 格式
match = re.search(r'\b[\w.-]+@[\w.-]+\.\w+\b', text)
if match:
    print("找到信箱:", match.group())
> 找到信箱: test@example.com

13 自訂迭代器 (Iterator)

實作 __iter__ 與 __next__ 打造可迭代物件。

class Counter:
    def __init__(self, max): self.max, self.n = max, 0
    def __iter__(self): return self
    def __next__(self):
        if self.n >= self.max: raise StopIteration
        self.n += 1
        return self.n

print(list(Counter(3)))
> [1, 2, 3]

14 字典推導式 (Dict Comprehension)

如同列表推導式，但用於快速生成字典 (Dictionary)。

keys = ['a', 'b', 'c']
# 將串列元素作為鍵，其 ASCII 碼作為值
ascii_dict = {k: ord(k) for k in keys}
print(ascii_dict)
> {'a': 97, 'b': 98, 'c': 99}

15 淺拷貝與深拷貝

了解多維結構中賦值、copy() 與 deepcopy() 的記憶體關聯。

import copy
a = [[1, 2], 3]
b = copy.deepcopy(a) # 完全獨立
a[0][0] = 99
print("A:", a)
print("B:", b)
> A: [[99, 2], 3]
> B: [[1, 2], 3]

16 型別提示 (Type Hinting)

提高程式碼可讀性並幫助 IDE 進行靜態檢查 (Python 3.5+)。

from typing import List

def get_average(scores: List[float]) -> float:
    return sum(scores) / len(scores)

avg = get_average([85.5, 90.0, 78.5])
print(f"平均: {avg:.2f}")
> 平均: 84.67
